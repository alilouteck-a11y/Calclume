# Phase 1 Content Standards

**Status:** Locked for Phase 1

## Voice and tone

- Professional, clear, approachable English
- Explain concepts without condescension
- Prefer concrete language over marketing superlatives

## Prohibited claims

- "Best," "most accurate," "#1," "trusted by millions"
- Invented usage statistics or search volumes
- Fabricated expert reviews or author credentials
- False "available now" language for unpublished tools

## Calculator copy rules

- Calculator usefulness before SEO copy
- Working surface near top of page (future pages)
- Consolidate related modes into one page
- No keyword-variation page spam

## Trust page standards

- Original, project-specific content (not lorem ipsum)
- Clearly separate current behavior from future plans
- Accurate privacy statements matching implementation
- No invented team, history, or credentials

## Homepage requirements

- Brand introduction with transparent calculation value proposition
- Illustrative example clearly labeled as non-interactive
- Statistics collection preview without fake calculator links
- Why CalcLume section with four concrete differentiators
- Methodology preview with link to full page
- Final CTA without exaggerated claims

## Directory page standards

- Label collections as "in preparation" when appropriate
- No links to nonexistent calculator detail pages
- Planning cards show status badges ("In preparation", "Planned")

## Formula and step presentation

- Formulas in monospace with overflow handling
- Steps numbered and labeled
- Interpretations in plain language with caveats when needed

## Localization standards

- English first
- Architecture supports future curated Arabic
- No automatic mass translation
- Localized content requires human review per Editorial Policy

## Source citation standards

- Only cite sources actually consulted
- Follow source hierarchy documented on Sources page
- No fake citations or broken reference links
